1. **Crear el entorno virtual:**  
   `python -m venv .venv`
2. **Activarlo:**  
   * En Linux/Mac: `source .venv/bin/activate`
   * En Fish: `source .venv/bin/activate.fish`
   * En Windows: `.venv\Scripts\activate`
3. **Instalar los paquetes:**  
   `pip install -r requirements.txt`
